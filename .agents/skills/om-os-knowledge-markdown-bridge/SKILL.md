# Om Knowledge OS: Markdown Knowledge Bridge

Use this skill when:
- Parsing and importing notes from `notion_os/*.md` or `my_notes/*.md`.
- Extracting concepts, citations, and actionable tasks from dialogue transcripts.
- Generating markdown documentation summaries and keeping INDEX.md updated.
- Preserving philosophical study notes (Vivarta Vada, Mati & Vivek, Uttarkashi land criteria).

## Procedures:
1. **Read Living Notes**: Read source markdown files in `notion_os/` or `my_notes/`.
2. **Decompose to Vault**: Ingest atomic concepts with tags (*Concept*, *Note*, *Source*, *Bookmark*, *Quote*, *Question*).
3. **Export**: Export Knowledge Vault items back to clean markdown files.
